## 📖 项目简介 (Overview)

**白给云博客 (`baigeiyun.world`)** 是面向下一代搜索引擎（Google / Bing / 百度 / 神马）与生成式 AI（ChatGPT / Perplexity / Claude / Gemini）深度优化的**高性能网络可观测性知识图谱与流量转化站**。

本项目立足于真实、客观、防篡改的网络工程评测，采用 **“一级导航 → 二级专题支柱 → 三级长尾内容集群”** 的立体蜂巢互联架构，全站输出 **182 个高信息密度页面**，总字数突破 60 万字，旨在消除跨境网络服务市场的虚标超卖信息差，为学术科研、外贸出海、远程协作及高频影音用户提供具备确定性依据的选型指南。

## 🚀 本地开发与部署指引 (Getting Started)

### 环境依赖
- [Node.js](https://nodejs.org/) `>= 18.0.0` (推荐 Node.js 20 LTS 或更高版本)
- [npm](https://www.npmjs.com/) `>= 9.0.0`

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务器
```bash
npm run docs:dev
```
启动后在浏览器打开 `http://localhost:5173` 即可预览完整站点并支持热更新。

### 3. 生成内容矩阵 (可选)
若调整了 `build-matrix.js` 中的品牌参数或专题集群，执行下述命令可一键重新生成全量 Markdown 文档：
```bash
node build-matrix.js
```

### 4. 生产环境静态编译 (SSG Build)
```bash
npm run docs:build
```
编译产物将输出至 `docs/.vitepress/dist/` 目录，耗时约 15~18 秒，并自动生成 `sitemap.xml`。

### 5. 本地预览生产构建产物
```bash
npm run docs:preview
```

### 6. Apache 生产环境部署
将 `docs/.vitepress/dist/` 目录中的所有文件（包含 `.htaccess`）上传至 Web 服务器根目录即可：
- 自动启用 TLS/HTTPS 301 重定向；
- 自动将 `www.baigeiyun.world` 301 重定向至规范主域 `baigeiyun.world`；
- 自动支持 Clean URLs（省略 `.html` 扩展名访问）；
- 自动处理静态资源 Gzip / Brotli 压缩传输与长效浏览器缓存。
