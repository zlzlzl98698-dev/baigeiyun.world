# 🔒 隐私权政策与数据安全声明 (Privacy Policy)

**生效日期**：2026 年 11 月 11 日  
**发布机构**：白给云网络可观测性实验室 (`baigeiyun.world`)

::: tip 【隐私承诺核心摘要 · Answer-First】
白给云博客坚决尊重并保护所有访问者的个人隐私权益。本站为纯静态托管的技术观察与测评知识库：
1. **零个人数据收集**：本站不设用户注册系统，不收集姓名、手机号、身份证等任何个人身份信息（PII）。
2. **零第三方侵入式追踪**：本站未接入任何第三方跨站行为追踪脚本、无百度统计、无 Google Analytics 广告指纹库、无第三方广告弹窗。
3. **本地搜索安全**：站内搜索功能完全在您的本地浏览器端（Client-side Memory）基于静态索引运行，您的搜索关键词绝不上传至任何云端服务器。
:::

## 一、 我们处理的信息范围

### 1. Web 服务器基础访问日志 (Server Access Logs)
当您访问 `baigeiyun.world` 时，我们的 Web 服务器（Apache/Nginx）会按照行业通用安全技术规范自动记录基础的 HTTP 访问元数据，包含：
- 请求的日期与时间戳；
- 请求的资源 URI 路径与 HTTP 状态码；
- 浏览器 User-Agent 字符串与大致网络协议版本；
- 访问者的公网 IP 地址（仅用于防范 DDoS 恶意攻击、CC 恶意刷量及维持服务器基础设施基本可用性）。

**数据留存周期**：上述日志仅在服务器安全日志中滚动存储 7 至 14 天，期满后由系统自动化覆写销毁，绝不用于任何商业画像或用户行为分析。

### 2. Cookie 与本地存储 (Cookies & LocalStorage)
本站不使用任何跨站营销追踪 Cookie。本站使用的本地存储仅限于：
- 浏览器的偏好设置缓存（例如 VitePress 本地搜索的最后索引时间）；
- 上述存储纯粹保存在您的本地终端设备中，您可以随时通过浏览器设置清空。

## 二、 外部第三方商业链接隐私隔离

在阅读本站测评文章时，您可能会点击跳转至第三方机场服务商或开源软件的外部网站（例如服务商官网注册页面）。

**请特别注意**：
1. 一旦您点击外链离开 `baigeiyun.world`，您即进入由该第三方独立控制的网站环境，其隐私政策与服务条款完全由该第三方制定并履行；
2. 为保护您的引用隐私，本站所有外链均已配置 `rel="nofollow sponsored noopener"` 属性，该属性可有效防止第三方网站获取本站的引用上下文（Referrer Leakage）；
3. 我们强烈建议您在第三方服务商网站输入任何支付凭据或邮箱前，仔细查阅该商家的隐私政策与服务协议。

## 三、 数据安全保障机制

1. **全站强制 HTTPS 加密**：全站所有通信均强制使用 TLS 1.3 现代高强度加密套件传输，防止任何网络中间人嗅探或篡改页面内容；
2. **静态架构免疫 SQL 注入**：本站采用静态站点生成（SSG）架构，不存在可被渗透的后端动态数据库，从根本上杜绝了数据泄露风险。
